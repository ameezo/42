# libft

## Description
Libft is a custom C library developed as part of the 42 curriculum. The objective of this project is to recreate essential standard C library (`libc`) functions from scratch, along with additional utility functions for memory management, string manipulation, and linked list processing. 

This library serves as a reusable foundation for future C projects at 42 where standard library usage is restricted.

---

## Library Overview

The library generates a static archive named `libft.a` containing the following modules:

* **Memory Functions:** `ft_memset`, `ft_bzero`, `ft_memcpy`, `ft_memmove`, `ft_memchr`, `ft_memcmp`, `ft_calloc`.
* **String Inspection & Conversion:** `ft_strlen`, `ft_strchr`, `ft_strrchr`, `ft_strncmp`, `ft_strnstr`, `ft_atoi`.
* **Character Checks & Conversion:** `ft_isalpha`, `ft_isdigit`, `ft_isalnum`, `ft_isascii`, `ft_isprint`, `ft_toupper`, `ft_tolower`.
* **String Manipulation & Generation:** `ft_strdup`, `ft_substr`, `ft_strjoin`, `ft_strtrim`, `ft_split`, `ft_itoa`, `ft_strmapi`, `ft_striteri`.
* **File Descriptor Output:** `ft_putchar_fd`, `ft_putstr_fd`, `ft_putendl_fd`, `ft_putnbr_fd`.
* **Linked List Utilities (Bonus):** `ft_lstnew`, `ft_lstadd_front`, `ft_lstsize`, `ft_lstlast`, `ft_lstadd_back`, `ft_lstdelone`, `ft_lstclear`, `ft_lstiter`, `ft_lstmap`.
